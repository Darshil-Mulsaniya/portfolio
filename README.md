# Darshil's Web Studio – Portfolio Website

A modern, responsive portfolio website built to showcase web development projects and services. Features a light Neumorphism design, smooth animations, interactive project cards, and contact options.

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome

### Features
- Responsive design for all devices
- Light Neumorphism theme
- Interactive project showcase
- Smooth animations
- Project category filters
- Contact and WhatsApp links

### Run Locally
1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Customize the content, project links, and contact details.
